# GreyLeads website

Static site for [greyleads.in](https://greyleads.in), hosted on Cloudflare Pages.

- Every push to `main` is deployed automatically by Cloudflare Pages (build command: none, output directory: `/`).
- `_headers` and `_redirects` are Cloudflare Pages config files.
- `sitemap.xml`, `robots.txt` and the SEO tags in each page are maintained by the monthly SEO check.
- See `DEPLOY-NOTES.txt` for go-live and SEO steps.
